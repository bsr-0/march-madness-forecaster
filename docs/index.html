Pool Optimizer is validated via 15-year leave-one-year-out backtest (2011–2026, excl. 2020; includes 2026 now that it has concluded). Against a real N=31 pool it achieves 11.3% P(1st) vs a 4.9% seed baseline, winning all 15/15 years (MeanRank p < 0.0001). Exhaustive Search tests all 64 possible champions (~6.2% P(1st), 8/15 years — right at the acceptance-gate boundary). Region Beam Search builds each region independently via beam search (~6.3% P(1st), 8/15 years — same boundary). Chalk (always the favorite) is a preference filter with no pool-backtest guarantee.
