How it actually went

Bracket board

Pool Optimizer is validated via 15-year leave-one-year-out backtest (2011–2026, excl. 2020; includes 2026 now that it has concluded). Against a real N=31 pool it achieves 11.2% P(1st) vs a 4.9% seed baseline, winning all 15/15 years (MeanRank p < 0.0001). Exhaustive Search tests all 64 possible champions (~6.2% P(1st), beating seed on MeanRank in 14/15 years). Region Beam Search builds each region independently via beam search (~6.3% P(1st), 14/15 years). Chalk (always the favorite) is a preference filter with no pool-backtest guarantee.

How accurate is the model, really?

Out-of-sample results from leave-one-year-out backtesting: for every tournament, the model is trained without that year and then asked to predict it cold. Every number below is computed from artifacts/loyo_pergame_predictions.json by scripts/generate_ml_backtest_data.py — model and baseline are scored on the same games, so the comparison is like-for-like. Nothing on this page is hand-entered.

Every model tested, against the seed baseline

Brier score is the headline metric (lower is better — it rewards being confident and right). BSS is skill relative to the seed baseline: positive means better than simply trusting seeds, 0 means no better, negative means worse. The baseline is a genuinely strong opponent — higher seeds win about of tournament games.

Caveats — read before trusting any of the above

  • These numbers depend on a bug fix, and older figures elsewhere may not include it. Tournament results were stored winner-first — every 2005–2015 game listed the winning team first, and 90.2% of all games did. Scored in that order a model is graded against a ~90% base rate instead of the real , which silently ruins accuracy and calibration figures and teaches any correction layer a bias that does not exist. Games are now re-oriented to an outcome-independent convention (better seed first) at the data-loading boundary. Brier, log loss and BSS are mathematically unaffected by that flip, so older Brier figures remain valid — but any previously published accuracy, calibration or correction-layer result predating the fix should be treated as suspect.
  • Researcher degrees of freedom are not fully audited. Hyperparameters were tuned while observing backtest results on these same years, and no multiple-testing correction is applied across the ~150 Brier evaluations per fit. Genuine out-of-sample performance is therefore likely somewhat worse than shown.
  • Sample sizes are small where it matters most. 63 games per tournament, and the late rounds are tiny — a single Final Four is 2 games. Round-level and year-level numbers should be read as indicative, not decisive.
  • The optimization target was held-out Brier, not BSS. The model was selected to minimize Brier; its skill-over-baseline was measured afterward, not optimized for.
  • This is prediction accuracy, not pool performance. This project's actual edge is bracket construction and selection, not forecasting games — every model family tested converges to roughly zero skill over the seed baseline, which is why production runs a 7-feature logistic regression rather than anything more elaborate. The Bracket Picker tab's P(1st) numbers come from a separate pool-simulation backtest and are not comparable to the metrics here.
