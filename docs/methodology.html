Model Overview

Blended rating model with Monte Carlo bracket simulation

The March Madness Forecaster combines team efficiency ratings (Barthag from Barttorvik) with Elo ratings and seed-based historical priors to produce game-level win probabilities. These probabilities feed into a Monte Carlo bracket simulator that runs 50,000 full-tournament simulations to estimate each team's chances of advancing to each round.

Key Design Principles

  • Leave-One-Year-Out (LOYO) validation — the model is trained on all years except the target year, preventing information leakage
  • Temporal integrity — no future data is used at any pipeline stage; features are computed from data available before tournament start
  • Calibration-first — raw probabilities pass through temperature scaling and shrinkage toward base rates to avoid overconfident predictions
  • Transparency — all hand-tuned constants are documented in a Researcher Degrees of Freedom (RDoF) audit registry

Data Sources

Multiple complementary data sources for robust predictions

  • Barttorvik — adjusted offensive/defensive efficiency, Barthag (win probability estimate), tempo, and Four Factors metrics
  • Elo Ratings — computed from game-by-game results with K=32, incorporating margin of victory and home-court adjustments
  • Seed Priors — historical base rates from 40 years of NCAA Tournament results (1985–2025) for each seed matchup
  • KenPom / Massey — external composite ratings for cross-validation and ensemble diversity

Probability Pipeline

Four-stage formula: raw → calibrate → shrink → clip

  1. Raw probability — computed from the rating differential between teams using a logistic function
  2. Temperature calibration — Platt scaling adjusts the sharpness of probabilities to match empirical accuracy
  3. Shrinkage — probabilities are pulled toward 0.5 to account for the inherent uncertainty of single-elimination games
  4. Clipping — final probabilities are clipped to [0.005, 0.995] to avoid extreme values that produce unbounded log-loss

Monte Carlo Simulation

The simulator runs 50,000 full brackets using logit-space noise injection (σ=0.12) per Lopez & Matthews (JQAS 2015). Each simulation draws a random outcome for every game weighted by the calibrated probabilities, then tracks which teams advance. The resulting championship, Final Four, and Elite Eight probabilities represent the fraction of simulations in which each team reaches that round.

Evaluation Framework

Rigorous backtesting with multiple metrics

Metrics

  • Brier Score — mean squared error of predicted probabilities vs binary outcomes (lower is better)
  • Log Loss — penalizes confident wrong predictions more harshly than Brier score
  • Accuracy — fraction of games where the predicted winner (>50%) was correct
  • Calibration (ECE) — expected calibration error measures how well probabilities match observed frequencies

Backtest Protocol

The model is evaluated using Leave-One-Year-Out cross-validation across 2018–2024 tournaments (378 total games). For each held-out year, the model is trained on all other years and predictions are generated without any knowledge of that year's results. The 2025 tournament serves as the true prospective holdout — the model was frozen before the tournament began.
