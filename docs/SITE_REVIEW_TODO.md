# Site review (2026-09-15)

Manual review of the rendered site (`docs/index.html` + `app.js`/`fit.js`/data files). Not yet triaged into individual issues/PRs — working list to pull from.

**Biggest limitation:** 2027 is still marked `not_started`, so none of this applies to an actual 2027 bracket until that data exists.

## What works
- Asks what you're optimizing for (chance of winning vs. expected points) and shows what each choice costs.
- States the 30-person pool assumption, flags near-tied alternatives, trains only on earlier seasons.
- Past seasons show actual results over your picks; has copy/print.
