LLM Council Report

Session #15 — 2026-04-06

Are locally-computed four factors (eFG%, TO%, ORB%, FTR) valid for backtesting, given that locally-computed barthag just diverged at r=0.73 from real Torvik?

Chairman's Verdict

Where the Council Agrees

Every advisor agrees: stop theorizing and measure. The debate about "counting stats" vs "derived rates" is unanswerable without data. Validation is a two-hour task. 8 of 12 features being potentially corrupted is not a tolerable unknown. The barthag r=0.73 is a live precedent. The live pipeline using Torvik while the backtest uses local values is a train/test mismatch by definition.

Where the Council Clashes

The Contrarian and Outsider argue the possession denominator problem is severe — the prior should be pessimistic. The Expansionist argues four factors are structurally simpler than barthag and the prior should be cautious but not catastrophic. Both are reasonable. The disagreement resolves through measurement, not argument. But the optimistic framing is motivated reasoning: "wanting four factors to be okay" is not the same as "four factors are okay."

Blind Spots the Council Caught

  • High correlation ≠ safe. Systematic errors biased toward specific team types won't show in aggregate r-values. Need residual analysis by subgroup.
  • Single-season validation is insufficient. Data coverage changes across seasons. Need per-season correlations checked for stability.
  • If Torvik opponent-adjusts four factors, there is no easy fix. Confirm raw vs adjusted before any validation.

The Recommendation

Do not trust locally-computed four factors until validated. Set the gate at r≥0.99 with no systematic residual bias, all eight features, all available seasons. Set the threshold before seeing results. If any feature fails, replace with Torvik's column or drop from the model entirely. Running corrupted features is worse than running fewer features.

The One Thing to Do First

Before running any correlation, check Torvik's documentation to confirm whether his published four factors are raw or opponent-adjusted. This takes five minutes and determines whether the validation is even asking the right question.

Full Advisor Responses

The Contrarian — "Same formula, same result" was already disproven

The "direct counting stats" argument is seductive and almost certainly wrong in practice. Four factors are rates, not raw counts — rates require denominators. TO% uses possessions, ORB% uses rebound opportunities. Torvik derives possessions from his own formula. ESPN uses different possession estimates. Even 1-2 possession errors per game compound across 30+ games.

Specific failure modes: (1) Possession estimation divergence. (2) Game coverage gaps. (3) Torvik may opponent-adjust four factors. (4) No validation data exists. Assume divergence until proven otherwise.

First Principles Thinker — Are inputs identical? Not formulas.

The question asked is "are the formulas correct?" The question that needs answering is "are we measuring the same things?" Possession denominators vary by source. The barthag catastrophe was caused by different game samples and data coverage, not wrong formulas. Same failure mode applies. The Cloudflare block is solvable, not an excuse to skip validation.

The Expansionist — If validated, it's a competitive advantage

Numerators are almost certainly correct — FGM, FG3M, FGA are raw counts. The divergence point is possessions. But if validated at r=0.97+, you've confirmed a clean backtesting surface. A validated local pipeline means you can extend backward, experiment with custom formulas. Barthag failed because it's a derived composite. Four factors are simpler. Validate, don't assume the worst.

The Outsider — Motivated reasoning: same trap, twice

The exact same trap, twice in a row. You fixed barthag because "locally computed diverges." Now the argument is "four factors are just counting stats, so they're fine." That's motivated reasoning. No validation data exists. Live pipeline uses Torvik, backtest uses local — train/test mismatch by definition. Cost of being wrong: 8 of 12 features corrupted.

The Executor — Two hours to know. Stop theorizing.

Pick one season, compute correlation and MAE for all eight features. Two hours. Either r≥0.99 (fine, move on) or r=0.73-style divergence (same problem). If divergence found, need fix path. Every hour theorizing is an hour you could spend knowing.
