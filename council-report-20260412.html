Key Disagreements

TENSION Diagnose opt_* vs. Just Deprecate

Executor: Deprecate in 15 minutes and move on. Zero risk, unblocks everything.

Contrarian + First Principles: You MUST understand why optimization inverts value. If the objective function is broken, it may infect leverage calculations downstream — the same leverage.py infrastructure powers both opt_* modes and the pool report's contrarian recommendations.

Chairman ruling: Deprecate now, but diagnose before next year. The contrarian concern about shared infrastructure is valid — if leverage.py's objective function is structurally broken for opt_*, check that it's sound for the parts you're still using.

TENSION Walk-Forward Validation Priority

Executor: Nice-to-have. Backtest is already out-of-sample by construction.

Statistician: New infrastructure that touches hyperparameters is a silent corruption risk. Must validate before trusting anything it produces.

Chairman ruling: Statistician is right in principle, but with the tournament approaching, this is deferred. Flag for post-tournament review.

TENSION Is 0.20% P(1st) Real Alpha?

First Principles: Random brackets get ~0.10% P(1st) in a 1000-person pool. You've doubled random. With N=13 years and enormous variance, this could be noise.

Statistician: Should have flagged this but focused on other issues. N=13 likely underpowered to detect this effect size.

Chairman ruling: This is the most uncomfortable question. A formal power analysis should be run post-tournament. For now, the construction modes are your best available option regardless — they're at least not worse than seed baseline, and they're dramatically better than opt_*.

  • Diagnose opt_* catastrophic failure (not optional)
  • Run sensitivity analysis — 2.51x leverage is a massive unvalidated bet
  • Validate leverage ratio against historical pool wins
  • Stop adding features — simplest mode wins
The First Principles Thinker

Core thesis: You're optimizing the wrong layer. Game-level prediction war is lost (BSS≈0). The actual edge lives in bracket construction topology — how you correlate picks across rounds.

  • Kill model improvement track entirely
  • Diagnose why opt_* inverts value (likely over-concentrating on leverage without respecting correlation)
  • Double down on construction mode research — explore more topologies
  • Validate public pick distribution accuracy
  • Question: is 0.20% P(1st) real or noise over 13 years?
The Statistician

Core thesis: N=13 dominates everything. Per-year variance (BestRank 2.1 to 171.7) means confidence intervals are enormous. You almost certainly lack power to detect real mode differences.

  • Fix missing aggregate section (blocking)
  • Run sensitivity analysis (NOT_EVALUATED is unacceptable)
  • Validate walk-forward harness against known results
  • Stop optimizing on BestRank alone — report both metrics
  • Pool size mismatch (1000→100) changes optimal strategy fundamentally
The Outsider

  • Pool size mismatch invalidates contrarian recommendations
  • Construction mode finding is the interesting result — double down there
